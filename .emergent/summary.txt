1.  **Web-Based Admin Dashboard:** A secure, multi-user platform for real estate agents to perform full CRUD operations on properties, clients, appointments, and property valuations. It must allow for agency-specific branding, including a customizable logo and color scheme.

2.  **AI WhatsApp Bot (Elettra):** An intelligent, conversational bot that engages with prospective clients via WhatsApp. It is responsible for understanding client needs, suggesting properties from the database, checking agent availability, and capturing new lead information. The integration is being migrated to WATI for production stability.

3.  **Native Mobile App (Tempocasa Tarquinia Pro):** A new iOS and Android application built with React Native and Expo. The primary user is the real estate agent, who needs to manage appointments, clients, and valuations on the go. A secondary client-facing version is a future possibility.

The entire system is built on a modern tech stack (FastAPI, React, MongoDB Atlas, Cloudinary) and is designed with an API-first approach to support both web and mobile clients from a single backend.
