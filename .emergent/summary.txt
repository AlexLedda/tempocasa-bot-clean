<product_requirements>
The project's goal is to build a sophisticated AI-powered real estate solution, comprising a management dashboard and an intelligent WhatsApp bot. The dashboard must support full CRUD (Create, Read, Update, Delete) operations for properties, clients, appointments, and valuations. A key feature is dynamic branding, allowing the agency to customize the application's logo and color scheme.

The WhatsApp bot, Elettra, is the core interactive component. It must engage with potential clients, understand their needs (e.g., property type, budget, location), suggest relevant properties from the database, check for appointment availability, and save new client information.

The architecture has evolved to ensure scalability and reliability. It uses Render for backend hosting, Vercel for the frontend, MongoDB Atlas for the database, and Cloudinary for image/asset storage. The WhatsApp integration has been migrated from the initial, unstable Baileys to Twilio, and is currently being transitioned to WATI for more robust production capabilities, eliminating the need for sandbox join commands by end-users. The system must be stable, responsive, and provide a seamless experience for both the real estate agents using the dashboard and the clients interacting with the bot.
</product_requirements>
